# skycope.co.za

Personal site, deployed on Vercel from GitHub.

The animated atmosphere is a WebGPU/WGSL shader built with
[vgpu](https://vgpu.sh). It includes interactive day, dusk, and night scenes,
with a CSS fallback for browsers without WebGPU.

```sh
npm install
npm run dev
npm test
```

Font: [Departure Mono](https://departuremono.com) by Helena Zhang (OFL).
