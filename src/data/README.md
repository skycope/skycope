# Celestial data

`stars.json` is a compact derivative of Olaf Frohn's d3-celestial data:

- https://github.com/ofrohn/d3-celestial/blob/master/data/stars.6.json
- https://github.com/ofrohn/d3-celestial/blob/master/data/constellations.lines.json

Retrieved 2026-09-08. Includes 2,851 stars through visual magnitude 5.5 and
all 88 Western constellation line figures. Star tuples are J2000 right ascension
(degrees), declination (degrees), visual magnitude, and B−V colour index.
Coordinates use the source catalog's J2000 epoch; precession, proper motion,
atmospheric refraction and light pollution are not modelled for stars.
Constellation lines are artistic guides connecting actual catalog positions.
